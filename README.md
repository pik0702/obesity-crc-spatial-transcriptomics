# obesity-crc-spatial-transcriptomics
Analysis code for GeoMx DSP and CosMx SMI spatial transcriptomic profiling of obesity-associated colorectal cancer.
# Obesity-associated colorectal cancer spatial transcriptomics

Analysis code supporting the study:

"Obesity Reprograms the Spatial Ecosystem of Colorectal Cancer through Early Epithelial Reprogramming and Immunosuppressive Remodeling"

This repository contains analysis scripts for GeoMx Digital Spatial Profiling (DSP) and CosMx Spatial Molecular Imaging (SMI) datasets.

## Repository structure

- `GeoMx/`: GeoMx DSP preprocessing, differential expression, pathway analysis, cell-type deconvolution, and visualization.
- `CosMx/`: CosMx SMI preprocessing, cell annotation, spatial analyses, cell-cell interaction analyses, and visualization.

## Data availability

GeoMx DSP data are available from Zenodo:
https://doi.org/10.5281/zenodo.21844663

CosMx SMI data are available from Zenodo:
https://doi.org/10.5281/zenodo.21844902

## Software

Analyses were performed primarily in R. Package versions and methodological details are provided in the manuscript and associated scripts.
