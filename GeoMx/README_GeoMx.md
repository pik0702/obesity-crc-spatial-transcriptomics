# Obesity-Associated Colorectal Cancer Spatial Transcriptomics

This repository contains the analysis code used for the GeoMx Digital Spatial Profiling (DSP) component of the study:

**“Obesity Reprograms the Spatial Ecosystem of Colorectal Cancer through Early Epithelial Reprogramming and Immunosuppressive Remodeling.”**

The GeoMx analysis includes preprocessing and quality control, Q3 normalization, differential expression and early-risk marker analysis, visualization, pathway analysis using ssGSEA, cell-type deconvolution using SpatialDecon, and processed CellPhoneDB ligand–receptor analysis.

## Repository structure

```text
GeoMx/
├── 01_preprocessing_QC_normalization/
├── 02_differential_expression_early_risk/
├── 03_visualization/
├── 04_ssGSEA_pathway_analysis/
├── 05_spatialdecon/
├── 06_cellphonedb_processed/
└── 07_cellphonedb_analysis/
```

### 01_preprocessing_QC_normalization

Performs GeoMx DSP preprocessing and quality control, including segment-level QC, probe-level QC, limit-of-quantification filtering, target detection filtering, and Q3 normalization.

The main processed object generated in this step is used as the input for downstream analyses.

### 02_differential_expression_early_risk

Performs epithelial differential-expression analysis across the four study groups:

- **NO−**: histologically normal tissue from non-obese individuals
- **NO+**: histologically normal tissue from obese individuals
- **TO−**: tumor tissue from non-obese individuals
- **TO+**: tumor tissue from obese individuals

The analysis uses log2-transformed Q3-normalized expression values and includes the statistical workflow used for differential-expression testing, early-risk gene assessment, the final 30-gene epithelial panel, Figure 2-related fold-change summaries, Supplementary Table S2-2 statistics, and four-group epithelial boxplots.

### 03_visualization

Contains scripts used for visualization of the GeoMx cohort and expression-level results, including plots associated with Figure 1 and related supplementary analyses.

### 04_ssGSEA_pathway_analysis

Contains the pathway-analysis workflow based on single-sample gene set enrichment analysis (ssGSEA).

ROI-level pathway enrichment scores are used to compare pathway activity across tissue compartments and obesity groups.

### 05_spatialdecon

Performs cell-type deconvolution of GeoMx DSP expression profiles using **SpatialDecon** with the **safeTME** reference matrix.

### 06_cellphonedb_processed

Contains processed CellPhoneDB ligand–receptor analysis outputs used for downstream epithelial–immune interaction analyses.

Files include processed interaction means, p-values, interaction scores, and ROI-level metadata used in downstream visualization and statistical analyses.

### 07_cellphonedb_analysis

Contains the downstream CellPhoneDB analysis and visualization code used to generate the epithelial–CD3 ligand–receptor results shown in the manuscript, including Figure 1H.

This workflow uses the processed CellPhoneDB outputs provided in `06_cellphonedb_processed/`.

## Analysis workflow

The recommended order is:

```text
01_preprocessing_QC_normalization
        ↓
02_differential_expression_early_risk
        ↓
03_visualization
        ↓
04_ssGSEA_pathway_analysis
        ↓
05_spatialdecon

06_cellphonedb_processed
        ↓
07_cellphonedb_analysis
```

The scripts are organized so that preprocessing is performed first and the resulting normalized GeoMx object is used for downstream analyses.

## Data availability

The GeoMx DSP dataset generated for this study is available through Zenodo:

**Park I, Kim J. GeoMx Digital Spatial Profiling Dataset of Obesity-Associated Colorectal Cancer. Zenodo. 2026.**  
https://doi.org/10.5281/zenodo.21844663

The deposited dataset includes:

- GeoMx Digital Count Conversion (DCC) files
- probe configuration (PKC) files
- de-identified sample and ROI annotation metadata
- normalized gene-expression matrix
- ROI-level ssGSEA results used for pathway analyses
- processed CellPhoneDB ligand–receptor analysis outputs
- ROI information used for downstream CellPhoneDB visualization and statistical analysis

All patient-related information in the deposited dataset has been de-identified.

## Running the analysis

The scripts were developed in R and are intended to be run in numerical order where applicable.

Before running a script:

1. Download the required input data from Zenodo.
2. Update the input and output paths at the beginning of each script if needed.
3. Install the R packages listed in the corresponding script.
4. Run the script from R or RStudio.

For example:

```r
source("GeoMx/01_preprocessing_QC_normalization/01_preprocessing_QC_normalization.R")
```

Downstream scripts can then use the processed object generated by the preprocessing workflow.

## Reproducibility

Key analysis parameters are explicitly defined within the corresponding scripts. Session information is saved by major analysis workflows where applicable.

For the differential-expression analysis, GeoMx Q3-normalized expression values are log2-transformed prior to downstream epithelial comparisons.

For CellPhoneDB visualization, the repository provides the processed interaction outputs together with the downstream analysis code used for the manuscript figures.
